# MVP Delivery Plan (4 Sprints)

## Sprint 1
- JWT auth and role claims.
- Jira project/sprint/story ingestion.
- Project initialization with immutable framework settings.
- Tenant isolation foundation.

## Sprint 2
- AI requirement quality analyzer with testability score persistence.
- AI test case generation with mandatory negative coverage.
- RTM base entities and Story→TestCase linkage.

## Sprint 3
- Automation script generation (Playwright + Selenium abstractions).
- GitHub branch/commit/PR automation.
- Script review + approval workflow.

## Sprint 4
- CI webhook listener + execution result ingestion.
- Definition of Done validator enforcement.
- Executive sprint quality dashboard with composite index.
